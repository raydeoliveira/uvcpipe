# Changelog — uvcpipe

## 0.1.0 — 2026-11-24
- **Foundation & Codec**: Clean-room C17 `Makefile` (`clang`/`gcc`/MinGW + `-DOSS_EDITION`), `include/uvcpipe_{domain,ports,core,adapters}.h`, USB HID Usage Page `0x07` scancodes, CH9329 Mode 0 packet codec/decoder, bounded `UvcStrBuf`, RFC 4648 base64, strict RFC 8259 JSON DOM parser, and baseline JFIF JPEG encoder + MJPEG validator.
- **UVC Capture & Snapshot Storage**: `capture_svc`, deterministic `sim_uvc` test-card/fixture adapter, macOS AVFoundation (`uvc_macos.m` with `activeFormat` lock & TCC check), Linux V4L2 (`uvc_linux.c` MJPEG/YUYV/RGB24 & `EINTR` signal abort), Windows Media Foundation (`uvc_win32.c` dynamic media-type refresh & bottom-up BGR24->RGB24 unpack), and `lstat()`/`FILE_ATTRIBUTE_REPARSE_POINT` atomic storage (`snapshot_fs.c`, `snapshot_fs_win32.c`).
- **CH9329 Serial HID & Safety**: `hid_safety` probe-before-write coordinator, `--dry-run` zero-TX preview, interruptible monotonic `sleep_ms` holds, automatic mouse press-hold-release with mid-click interrupt release, `sim_serial` responder + TX audit log, and POSIX/Win32 serial & signal adapters (`SIGPIPE` ignored cleanly).
- **Live Viewer & Security Hardening**: Loopback `127.0.0.1` HTTP/1.1 MJPEG `viewer_http` with `8192`-byte header cap, monotonic clock, `Host`/`Origin` DNS-rebinding `403` guard, `Content-Security-Policy`, and `X-Content-Type-Options: nosniff`.
- **Polar.sh Licensing, MCP & Packaging**: Full `uvcpipe license status|activate|validate|deactivate [--force]` lifecycle enforcing non-future `<= 14d` `validated_at` timestamps; stdio JSON-RPC 2.0 `uvcpipe mcp` server negotiating `"2025-03-26"` / `"2024-11-05"` with MCP tool annotations; Linux udev rules (`99-uvcpipe.rules`), MCP client snippets (`mcp-configs.json`), `SKILL.md`, `server.json`, `glama.json`, Homebrew formula, and deterministic macOS (`.tar.gz` + `.mcpb`), Linux (`.tar.gz`), and Windows (`.zip`) release archives.
